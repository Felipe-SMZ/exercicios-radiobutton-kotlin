# Exercícios RadioButton Kotlin

Aplicativo Android desenvolvido em Kotlin no Android Studio com foco em prática de:

- RadioGroup
- RadioButton
- Intent
- Splash Screen
- Navegação entre Activities
- Validação de formulários
- Cálculos matemáticos
- Strings formatadas
- Tratamento de erros

---

# Funcionalidades

## Splash Screen
Tela inicial exibida ao abrir o aplicativo.

## Menu Principal
Menu para escolher entre:

- Geometria de Áreas
- Lei de Ohm

---

# Exercício 1 — Geometria de Áreas

Permite calcular áreas utilizando RadioButtons.

## Opções

- Círculo
- Retângulo
- Triângulo

## Fórmulas

### Círculo

A = π × r²

### Retângulo

A = base × altura

### Triângulo

A = (base × altura) / 2

## Recursos

- Validação de campos
- Tratamento de erros
- Toasts de aviso
- Resultado formatado

---

# Exercício 2 — Lei de Ohm

Permite calcular:

- Tensão (V)
- Corrente (I)
- Resistência (R)

## Fórmulas

### Tensão

V = R × I

### Corrente

I = V / R

### Resistência

R = V / I

## Recursos

- Validação de entradas
- Proteção contra divisão por zero
- Toasts de erro
- Resultado formatado
